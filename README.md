# Gasipro

Une application de gestion de services conçue pour gérer les commandes des clients via deux interfaces distinctes.

## Fonctionnalités & Rôles

- **Interface Caissier :** Valider les commandes, accéder à l'ensemble des historiques de transactions et consulter les statistiques du système.
- **Interface Comptoir :** Créer les commandes clients et consulter son propre historique.

## Tech Stack

- Angular & TypeScript
- Tailwind CSS
